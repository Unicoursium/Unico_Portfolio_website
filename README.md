# Unico Yin — Portfolio prototype

A responsive, original portfolio for Unico Yin, Design Engineering. All project studies are explicitly marked sample content. Contact information is pending; no message form or external backend is included.

## Preview

Run from this directory:

```sh
python3 -m http.server 8080
```

Open http://localhost:8080. No build step or package installation is required.

## Edit

- `index.html`: identity, introduction, about and contact copy.
- `style.css`: colours, typography, layout and responsive styles.
- `app.js`: the `projects` array holds project content. Replace sample artwork from `art()` with your own images when ready.

The site loads DM Sans and Space Mono from Google Fonts, with local fallback fonts. Original procedural SVG artwork needs no external assets. Theme preference is saved only in the visitor’s browser.

## Publish with GitHub Pages

1. Put these files at the root of a GitHub repository.
2. In repository Settings → Pages, choose Deploy from a branch, select your branch and `/ (root)`.
3. Once published, add your personal domain in Pages settings and configure its DNS following GitHub’s custom-domain documentation.

No domain is configured yet. No account connection, deployment or publication has been performed. Project links use fragment URLs, so they also work on GitHub Pages repository subpaths.

Before public launch, replace the four illustrative studies and add your actual contact information.
